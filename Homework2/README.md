# MyKanban

A single-page Kanban board for personal task tracking. Built for Homework 2 of the
[AI Dev Tools Zoomcamp](https://github.com/DataTalksClub/ai-dev-tools-zoomcamp).

- One board, fully customizable columns (add / rename / delete / reorder)
- Cards with title, notes, optional due date
- Drag & drop between columns, order persists in a database

See `_docs/specs.md` for the full spec.
